# Endless Runner — Premium 3D

3D endless runner with a more realistic humanoid character, black & gold UI, lane switching, jump, slide, coins, and obstacles.

## Play locally

```bash
npx serve .
# or
python3 -m http.server 3000
```

## Deploy on Vercel

1. Import this repo on Vercel
2. Framework: Other
3. Build: empty | Output: `.`
4. Deploy

## Controls

- Left/Right: A D or arrows
- Jump: W / Up / Space
- Slide: S / Down
- Mobile: swipe
